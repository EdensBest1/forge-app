# Forge Career+

Forge Career+ is a paid-feature placeholder for blue-collar career support. It is not live for billing yet.

## Planned Features

- AI resume builder
- AI cover letter and application helper
- Trade school application support
- Apprenticeship application support
- Scholarship/grant search
- Interview prep
- Priority worker profile
- Priority job placement alerts
- Career dashboard

## MVP Behavior

When someone checks Forge Career+ or asks for resume help, the static MVP saves a resume request in local state and shows it in Admin Academy. Pricing, payment, secure uploads, account entitlements, and production billing are not active.

## Launch Requirements Before Charging

- Published pricing and refund terms
- Secure auth and account access
- Secure document upload/storage
- Payment processor configuration
- Human review process for AI-generated resumes and application materials
- Clear disclaimers that Forge Career+ cannot guarantee jobs, admission, scholarships, financial aid, union acceptance, licensure, or placement
