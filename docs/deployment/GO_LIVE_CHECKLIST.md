# Go-Live Checklist

- Confirm GitHub repo is clean.
- Confirm environment variables are configured.
- Confirm database migrations are safe.
- Confirm storage bucket exists.
- Confirm upload paths are mapped.
- Confirm no secrets are committed.
- Confirm forms save correctly.
- Confirm existing sections still work.
- Confirm admin can review leads/provider applications.
- Confirm production build passes.
- Deploy to staging first.
- Review staging.
- Deploy to production only after approval.
