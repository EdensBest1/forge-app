# Wave 1 Outreach Playbook

Wave 1 is top 50 per category, not the entire board.

## Sequence

1. Export private leads after `MONDAY_API_TOKEN` is set.
2. Run dedupe and scoring.
3. Review do-not-contact and consent fields.
4. Review top 50 per category manually.
5. Assign landing pages with public lead codes.
6. Approve a small manual call-first wave.
7. Ask permission before sending SMS/email links.
8. Log outcome and consent.
9. Hold all automated outreach until compliance review.

## Success Metrics

- Permission rate
- Link sent after permission
- Page views by public lead code
- Access requests
- Stitch fit
- Forge job interest
- North Star consult interest
- Suppression requests honored

## Stop Conditions

- Any do-not-contact mismatch
- Any complaint
- Any unclear consent
- Any wrong segment
- Any unsupported claim in script/template
