# Landing Page Assignment Rules

Do not put phone numbers, emails, owner names, license numbers, or private CRM details in URLs.

## Safe Tracking Params

Allowed:
- `lead_code`
- `utm_source=monday`
- `utm_campaign=oregon_operator_wave_1`
- `segment`
- `license_type`

Forbidden:
- phone
- email
- owner name
- license number
- address
